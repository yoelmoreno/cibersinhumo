# 🟢 Ciber Sin Humo

Ciber Sin Humo es una plataforma web centrada en la divulgación de ciberseguridad de forma clara, visual y accesible.

El objetivo principal es ofrecer contenido educativo combinado con recursos prácticos, enfocado especialmente a principiantes y usuarios interesados en mejorar su seguridad digital.

---

## 🎯 Objetivo del proyecto

- Explicar conceptos de ciberseguridad de forma sencilla
- Centralizar recursos útiles (herramientas, navegadores, plataformas)
- Servir como apoyo a contenido en redes sociales (TikTok / YouTube)
- Crear una identidad visual moderna y atractiva dentro del sector

---

## 🧠 Concepto

Mantis Lab combina:

- 🔐 Educación en ciberseguridad  
- 🎥 Contenido audiovisual (vídeos cortos y largos)  
- 🧰 Recursos prácticos  
- 🌐 Diseño visual futurista (estética cyberpunk)  

---

## 🏗️ Estructura inicial de la web

### 1. Home
- Hero visual con animación (mantis + fondo dinámico)
- Mensaje principal
- Accesos rápidos a contenido

---

### 2. Vídeos
- Contenido embebido desde redes sociales
- Organización por categorías:
  - Hacking básico
  - Privacidad
  - Herramientas
  - OSINT

---

### 3. Recursos
Sección clave del proyecto.

Incluye:
- Navegadores seguros
- Herramientas de ciberseguridad
- Plataformas de aprendizaje
- Libros recomendados

---

### 4. Blog
- Artículos explicativos
- Apoyo a contenido en vídeo
- Explicaciones más detalladas

La web sigue una estética:

- Fondo oscuro
- Tonos verde neón
- Elementos futuristas
- Animaciones sutiles (no intrusivas)

⚠️ Prioridad: equilibrio entre diseño visual y funcionalidad

## ⚠️ Notas importantes

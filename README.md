# cibersinhumo
Ciber Sin Humo es un proyecto de divulgación en ciberseguridad pensado para explicar lo que realmente importa, de forma clara, directa y sin complicaciones. Aquí no hay teoría innecesaria: solo contenido útil, herramientas reales y conceptos explicados desde cero para que cualquiera pueda empezar a entender cómo funciona la seguridad en internet.

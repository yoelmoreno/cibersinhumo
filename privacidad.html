Política de privacidad

1. Responsable del tratamiento

El responsable del tratamiento de los datos personales recogidos en esta web es Yoel Moreno de Vega. Puedes contactar escribiendo a mantislabs.es@gmail.com.

2. Datos que se pueden recoger

El formulario de sugerencias puede recoger los siguientes datos:

  • Nombre o alias, si decides indicarlo.
  • Email, si decides indicarlo para poder recibir respuesta.
  • Mensaje o sugerencia escrita.
  • Datos técnicos tratados por el proveedor externo del formulario o correo, como dirección IP, fecha, hora, navegador u otros datos necesarios para prestar el servicio y prevenir abusos.
  • Datos técnicos y de navegación tratados mediante Google Tag Manager / Google Analytics si aceptas las cookies de analítica, como páginas visitadas, dispositivo, navegador, fecha, hora o ubicación aproximada.
  • Si usas la herramienta "Ver mi IP", el proveedor externo de consulta IP puede tratar tu dirección IP para mostrar datos aproximados como país, ciudad, región, proveedor de red y zona horaria.

3. Finalidad

Los datos se tratan para gestionar las sugerencias enviadas por el formulario, valorar ideas de vídeos o contenido, responder si procede, mostrar información aproximada de tu IP pública cuando solicitas usar esa herramienta, medir el uso de la web mediante analítica si das tu consentimiento y mejorar el contenido.

4. Base jurídica

La base jurídica del tratamiento es el consentimiento de la persona usuaria al enviar voluntariamente el formulario, usar voluntariamente la herramienta de consulta IP y aceptar esta política de privacidad. En el caso de Google Tag Manager / Google Analytics, la base jurídica es el consentimiento prestado al aceptar las cookies no necesarias.

5. Conservación

Los datos se conservarán solo durante el tiempo necesario para gestionar la sugerencia, responder si procede y mantener un control razonable de las ideas recibidas. Después podrán eliminarse cuando ya no sean necesarios.

6. Destinatarios

No se venden ni ceden datos personales a terceros. Los datos podrán ser tratados por el proveedor técnico del formulario y/o del servicio de correo utilizado para recibir las sugerencias, por el proveedor externo de consulta IP si usas esa herramienta, y por Google como proveedor de analítica si aceptas las cookies correspondientes.

7. Derechos de las personas usuarias

Puedes ejercer tus derechos de acceso, rectificación, supresión, oposición, limitación del tratamiento y portabilidad escribiendo a mantislabs.es@gmail.com. Para gestionar la solicitud puede ser necesario acreditar tu identidad.

8. Reclamaciones

Si consideras que el tratamiento de tus datos no se ajusta a la normativa, puedes presentar una reclamación ante la Agencia Española de Protección de Datos: www.aepd.es.

9. Información sensible

No envíes información sensible por el formulario, como datos médicos, financieros, contraseñas, documentos de identidad, datos de menores o cualquier información que no sea necesaria para proponer una sugerencia de contenido.

10. Cambios en esta política

Esta política puede actualizarse para adaptarse a cambios legales, técnicos o de funcionamiento de la web. La fecha de actualización aparecerá indicada al inicio.
